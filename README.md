# CTRL-TECH — plateforme e-commerce

Socle frontend conforme au rapport CTRL-TECH : React, TypeScript, Vite, Tailwind CSS, React Router, TanStack Query, React Hook Form et Zod. Architecture cible backend : Vercel Functions / Node.js / TypeScript, Neon PostgreSQL, Drizzle ORM et Neon Managed Better Auth.

## Développement
```bash
npm install
npm run dev
```
## Build
```bash
npm run build
```

Le catalogue présent est une base de démonstration. Les prix, stocks, variantes, garanties, visuels officiels, paiements et conditions de livraison doivent être validés par CTRL-TECH. La sélection d'articles côté navigateur n'est pas une commande et aucun paiement réel n'est activé.

Le rapport de référence définit les critères de réalisation et de mise en production. Cette branche rétablit le socle frontend React/Vite et la direction artistique Precision Retail.
